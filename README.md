### 🌵 Botany
**[Mesemb Marathon](https://lithops.life)** ([source](https://github.com/Square-Pot/lithops-life)) is a non-profit
community project I run. Every year growers sow Aizoaceae seeds on the same day and follow
their seedlings for at least a year, sharing photos, comparing results and learning from
each other. The site holds the yearly marathons, competitive species and their progress tables.

**[Square-Pot](https://github.com/Square-Pot)** is my GitHub organization of tools for running
a plant collection: plant database, pot labels with Data Matrix codes, photo sorting, a Telegram bot.
